# Portfolio 5: Distributed and Cloud Database Exercise

## Overview

This portfolio examines how a distributed and cloud-based database architecture could support the University Student Result Portal.

## Objectives

- Explain the role of distributed databases.
- Describe how cloud database services could support the portal.
- Identify benefits and challenges of distributing student result data.
- Propose an architecture for availability, scalability, and data protection.

## Activities

- Designed a proposed distributed database architecture for the University Student Result Portal.
- Identified the main application and database components.
- Examined data replication, backup, access control, and availability considerations.
- Documented the benefits and limitations of the proposed approach.

## Evidence Files

The architecture description and supporting analysis will be documented in this folder.

## Conclusion

This portfolio demonstrates how distributed and cloud database concepts can be applied to a university student result management system.
