# Portfolio 4: NoSQL and Advanced Data Models

## Overview

This portfolio explores NoSQL databases and document-based data modelling using the University Student Result Portal case study.

## Objectives

- Understand the concept and characteristics of NoSQL databases.
- Represent student, course registration, and result information using JSON documents.
- Compare relational database structures with document-oriented data models.
- Discuss the benefits and limitations of using NoSQL for student result management.

## Activities

- Design a sample document model for student result information.
- Create sample JSON data based on the University Student Result Portal.
- Examine how related information can be embedded in a document.
- Compare the document model with the existing SQLite relational database.

## Evidence Files

The portfolio will include a JSON data file, a relational-versus-NoSQL comparison, and supporting documentation.

## Conclusion

This portfolio demonstrates how document-oriented data modelling can represent student result information and explains when a NoSQL approach may be useful.
