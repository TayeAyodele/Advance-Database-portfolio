# Portfolio 1 – Database Design and Modelling

## Course
MIT 8103 – Advanced Database Systems

## Academic Session
2026/2027 First Semester

## Case Study
University Student Result Portal

## Overview
This portfolio focuses on the design and modelling of a database for a University Student Result Portal. The system is designed to manage students, departments, programmes, courses, course registrations, lecturers, semesters, and student results.

The portfolio demonstrates database design concepts, including entity-relationship modelling, relational schema design, primary and foreign keys, integrity constraints, and database normalisation.

## Objectives
- Design an appropriate database structure for a University Student Result Portal.
- Identify entities, attributes, relationships, primary keys, and foreign keys.
- Develop a relational database schema.
- Apply database normalisation principles.
- Document the design decisions and constraints used in the database.

## Portfolio Contents
The following files are included in this portfolio:

1. `case-study.md` – Describes the case study, users, purpose, and main operations of the system.
2. `University Student Result Portal ER Diagram.pdf` – Presents the entity-relationship diagram.
3. `relational-schema.md` – Defines the database tables and their attributes.
4. `key-constraints.md` – Documents primary keys, foreign keys, uniqueness, and referential integrity constraints.
5. `normalisation.md` – Explains the application of First, Second, and Third Normal Forms.

## Expected Outcome
The portfolio provides a structured database design that supports accurate record management, reduces unnecessary data duplication, and improves the retrieval and maintenance of student academic records.
