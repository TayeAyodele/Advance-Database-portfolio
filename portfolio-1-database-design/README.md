# Portfolio 1 - Database Design and Modelling

## Course
MIT 8103-Advance Database Systems

## Academic Session
2026/2027 First Semester

## Case Study
University Student Results Portal 

## Overview
This portfolio focuses on the design and modelling of a database for a 
university Student Result Portal.
The system is design to manage students, programmes, courses, course registrations,
lecturers, semesters, and students results.


The portfolio demonstrates database design concepts including entity-relationship modelling,
relational schema design,primary and foreign keys,constraints, 
and database normalisation. 

## Objectives 
- Design an appropriate database structure for a 
University Student Result Portal.

- Identify entities, attributes, relationships,
 primary keys and foreign keys.

- Develop a relational database schema.

- Apply database normalisation
 principles.

- Document the design decisions and 
constraints used in the database.
