Overview
This portfolio focuses on the design and modelling of a database for a university Students REesult portal. The system is designed to manage students,programmes,courses,course rgistrations,lecturers,semesters and student results.

The portfolio demonstrates database design concepts including entity relationship modelling,relational schema design,primary and foreign keys,constraints,and database normalisation.

Objectives
.Design an appropriate database structure for a University Students Result Portal,
.Identify entities,attributes,relationships,primary keys, and foreign keys.
.evelp a relational database schema.
.Apply database normalisation principles.
.Document the design decisions and constraints used in the database.
