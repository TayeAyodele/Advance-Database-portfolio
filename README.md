
# Advanced Database Systems Practical Portfolio

**Course:** MIT 8103 – Advanced Database Systems  
**Programme:** Master of Information Technology  
**Case Study:** University Student Result Portal

## Overview

This repository contains the practical portfolio activities completed for Advanced Database Systems. The University Student Result Portal is used as the case study to demonstrate database design, query processing, transaction management, NoSQL data models, and distributed and cloud database concepts.

## Portfolio Activities

### Portfolio 1: Database Design and Modelling
Database design and modelling for the Student Result Portal, including the ER diagram and relational database structure.

### Portfolio 2: Query Processing and Optimisation
SQL queries, query results, execution plans, indexing evidence, and performance analysis.

### Portfolio 3: Transactions and Concurrency
Transaction operations, commit and rollback testing, isolation-setting checks, and transaction analysis.

### Portfolio 4: NoSQL and Advanced Data Models
Practical exploration of NoSQL concepts and advanced data models.

### Portfolio 5: Distributed and Cloud Database
Practical exploration of distributed and cloud database concepts using the Student Result Portal case study.

## Tools Used

- DB Browser for SQLite
- SQLite
- GitHub

## Repository Structure

Each portfolio activity is organised in its own folder. The folders contain the relevant SQL scripts, documentation, diagrams, and evidence files for the activities.

## Conclusion

This practical portfolio demonstrates the application of advanced database concepts through the design, implementation, testing, and documentation of a University Student Result Portal.
